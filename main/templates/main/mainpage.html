🦁 Django 첫페이지 만들기 🦁
  • 1. main - Templates - main 폴더 생성 후 mainpage.html 파일 생성(해당 html 파일에 사이트에 보여줄 코드 작성)
  • 2. views.py에서 mainpage가 렌더링 될 수 있도록 코드 작성
  • 3. urls.py에서 main에서 views를 끌어다쓰도록 코드 작성
  • -> python manage.py runserver 실행!
🦁 Template 언어 🦁
  • *Template 언어* : python의 변수나 문법을 html에서 사용할 수 있도록 해주는 언어 (url 연결, 변수 사용, 반복문, 조건문, 필터)
  • 1. html 링크 연결 : 각 html 파일 내부에서 nav class에서 url '파일명' 코드를 적어 urls.py에서 지정한 name을 이용하여 페이지 내에서 해당 페이지로 이동할 수 있도록 해주는 기능
  • 2. 변수 사용 : views.py에 mainpage 메서드 복붙 (render 매서드 호출 시 context를 담아서 보낸다.)
  • 3. 반복문 & 조건문 : (사진추가)
  • 4. Template 필터 : 주로 변수와 함께 쓰이며 원하는 형태로 값을 변환하기 위해 사용
🦁 중복되는 html 파일 정리 🦁
  • 1. template 상속 : project - templates 폴더 생성 후 base.html 파일 생성 (사진추가) / settings.py에서 project 폴더에 있는 템플릿을 찾을 수 있도록 import os, 'DIRS'코드 작성
  • 2. navbar 분리 : 코드의 반복을 줄이기 위해 project - templates - shared 폴더 생성 후 _navbar.html 파일 생성(_로 시작하는 이유 : 브라우저에서 보이지 않아서 개발자들간의 소통을 위한 관례) / base.html에서 잘라낸 부분에 include를 이용하여 _navbar.html 상속시키기
🦁 정적 파일 분리 🦁
  • 1. 정적 파일 폴더 생성 : project - static - css / images 폴더 생성 후 css 폴더 내부에 project.css파일 생성
  • -> base.html에서 css 연결 코드 작성(맨위에 load static 작성) / mainpage.html에서 image 넣는 코드 작성(맨위에 load static 작성)
  • -> settings.py에서 정적 파일 경로 설정
